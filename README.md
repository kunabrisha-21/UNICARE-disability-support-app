# ♿ UNICARE – Disability Support App

> An accessibility-focused web application designed to support people with disabilities by providing easy access to safety, healthcare, care services and personalized support.

## 🌐 Live Demo

[Open UNICARE](https://unicare132.base44.app/)

## 🎯 Problem Statement

People with disabilities may face difficulties accessing emergency assistance, healthcare services, care support and accessible digital resources.

UNICARE aims to bring important support services together in one simple and accessible platform.

## 💡 Objective

The objective of UNICARE is to provide a user-friendly digital platform that helps people with disabilities access essential services and support more easily.

## ✨ Key Features

- 🚨 Emergency SOS
- 👩‍⚕️ Healthcare consultations
- 🤝 Care services
- 📞 Emergency contacts
- ⚙️ Personalized accessibility settings
- 🎮 Entertainment
- ♿ Accessibility-focused interface

## 🛠️ Technology

- Web Application
- Responsive User Interface
- Accessibility-focused design
- Base44 platform
